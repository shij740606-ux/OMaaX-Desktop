## 已修复问题及限制

- 原页面会议列表回包被当作数组，导致运行时异常：按 `payload.items` 读取。
- 取消/失败删除不再提前清空本地科研任务状态。
- SSH 通道不是 TCP Socket：HTTP 超时改用独立计时器，避免进程退出。
- 桌面跨来源 iframe 初始导航可加载，跨站 API 请求仍禁止。
- 实机安装验收发现主页面 CSP 未允许科研 iframe：只增加本机回环 iframe 来源，保留其余安全策略，并重新打包验收。
- 前端请求失败也会清理超时器；上传超时/取消会结束等待，已取消请求不会再次发送；说明文字改为功能使用提示。
- 原服务未开放 ZIP 工程编译与完整科研汇报接口；这两个草稿入口不展示。论文重排版支持单文件 `.tex`，可以生成并下载 PDF。
- 期刊指标/会议日期沿用服务资料，保留来源及待核验标记。本轮没有逐条重新核验外部资料。
