# OMaaX 0.4.23：强制登录和账号隔离

日期：2026-10-17。基线 0.4.22（1327a76）。依据桌面《PlantAI鉴权接入文档.md》及用户确认实施。

## 行为

- 使用 `/api/auth/status`、`login`、`me`、`logout`。必须启用 `AUTH_ENABLED`，无离线匿名降级；账号由中枢 `/admin/` 创建，不提供注册。
- 密码仅用于本次登录；令牌留在系统安全存储，前端拿不到令牌，不写入模型环境、SSH 请求或普通配置。拒绝鉴权接口重定向。
- 退出先写入持久化退出标记，再清理系统凭据；即使系统暂时回读旧凭据，也不能恢复登录。重新登录需写入并回读核验新凭据后才解除标记，已单独复测。
- 采用 `accounts/profiles/<中枢摘要>/<用户 UUID>`；独立设置、对话、SSH 列表、附件、工作区、日志及 WebView 数据。切换账号重启本地程序，停止旧智能体。旧版根目录不迁移，不归属首位登录用户。
- 主进程统一检查权限，未知命令默认拒绝。`qa` 提供对话，`bioflow` 提供分析及流程对话。管理员也不能绕过删除与覆盖审批。
- 原生 SSH MCP 每次调用验证账号；模型只能调用受控服务器工具，不能使用终端、任意文件工具、其他 MCP 或审批工具绕过权限。环境检查、安装、日志读取、修改安装方案、重试保持开放。
- 必须确认账号保护插件已在本次智能体启动时注册，否则停止启动。原有工作流单调权限护栏及步数预算例外继续生效。
- 原生界面授权缓存最多 5 秒；后台每 15 秒重新检查，中枢网络请求超时 12 秒。停止本机智能体不等于取消已提交的服务器任务。
- 旧平台全局凭据接口、未隔离远程智能体和自定义 MCP 暂停开放。知识库继续不出现在导航中。
- 本机授权请求记录到对应账号 `logs/account-access.jsonl`，不写密码、令牌和请求正文；记录请求获得授权，不将其当作任务完成证据。中枢审计仍仅覆盖中枢请求。

## 验收边界

界面使用模拟桥接，原生契约使用本机模拟中枢；这些通过不等于真实中枢账号验收。没有运行真实 SSH 环境安装、付费模型自主修复或完整生物学分析。

本次提供应用级隔离，不是 Windows/SSH 操作系统级隔离。使用同一系统账号的人仍可直接访问该账号的磁盘或服务器文件；需要强隔离时应使用不同系统及 SSH 账号。局域网 HTTP 不加密传输，这是用户明确选择的部署方式。

测试证据位于 `validation-local/auth-*`、`validation-local/model-workflow-browser/result.json` 和 `deploy/local/fixed-workflows-20261013/sdk-tests/latest.json`。这些本机测试工件不包含真实账号密码或中枢令牌，不提交安装包及编译缓存。
