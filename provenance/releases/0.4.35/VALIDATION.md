# OMaaX 0.4.35

本次将待发布的界面、MCP、绘图与知识库排版修改一起发布。

- 本机工作目录、添加项目、结果列表、图片预览、Git 与打开路径不再要求目录属于软件账号；路径仍须存在且可由操作系统访问。
- 保留启动登录、每个账号各自保存的配置与对话，以及知识库 qa 授权。服务器按 SSH 凭据连接，教育科研不要求软件账号绑定服务器。
- 恢复图像服务与外部 MCP 配置。外部 MCP 每次执行仍需确认，固定流程与删除保护不变。
- 知识库结果在上、输入框在下；保留提问和文献检索。账号操作移入设置，分析入口更名为分析结果，清理社区名称和多余提示。

验证记录将于安装验收完成后补齐。安装使用包备份与用户数据哈希核对，不移动或合并用户数据。
