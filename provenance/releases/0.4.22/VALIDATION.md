# OMaaX 0.4.22 复核与修补

日期：2026-10-17。基线：0.4.21（0a934b3）。对照对话 01a14557-f586-70d1-a00f-1f7add44d8ff 的环境自主配置需求。

## 发现与修复

1. 普通问答步数护栏会在 20 步或 420 秒后向流程对话插入禁止继续调用工具的收尾指令。现对有效绑定的流程对话跳过此提醒；普通问答和无效绑定仍保留原行为。删除与工具权限护栏独立保留。
2. 后台环境安装进程启动异常会留下无 PID 的 queued 任务，阻止后续重试。现写入失败状态与错误日志，再次 workflow_prepare 可创建新任务。
3. 发布前只同步 workflow-guard，可能漏打包修改后的 step-guard。现同步两个插件。

## 已验证

- Python 后端回归：155 项，141 通过、14 平台条件跳过。涵盖环境配置、错误日志、方案修订重试、删除和覆盖保护、输入只读。
- 插件单元测试：10 项通过，包括超过 200 步和模拟一小时后继续执行、普通对话仍收尾、无效绑定不放行。
- 实际 DSH SDK：普通对话在第 200 步收到原提醒，绑定流程后不再收到停止工具指令；权限护栏仍拒绝越权，模型不能伪造会话身份。使用真实 SDK、本地测试工具，无付费模型调用。

- webapp-testing 无头 Edge：11 项检查通过、0 页面错误；模型交接、结果页面和知识库隐藏保持正常。
- 实际 SDK 的四个环境工具均可执行；已注册的删除确认工具在执行前被拦截。

## 保留的边界

模型可以检查依赖、提交安装方案、读取失败日志、修订方案后重试，但服务器账号仍需具备可用的非 root Podman/cgroup 基础条件。系统管理员权限、账号未授权服务器、删除/覆盖确认和初始分析计划确认不自动绕过。用户原始数据不挂载到安装脚本环境。

未进行真实 SSH、实际 Linux 环境安装或完整生物学流程验收，不能保证所有网络和系统环境下模型都能自行解决错误。仅改变步数收尾机制，不改变模型提供商的限额或外部服务可用性。
