# OMaaX 0.4.27 验证记录

## 来源与差异

按用户指定的 `http://192.168.0.175:5181/` 读取运行进程所在工作树，与 0.4.26 桌面版逐文件比较。源码来源与哈希见 `desktop/education/SOURCE.json`。

实质新增：第九个“科研汇报助手”和多文件 ZIP LaTeX 工程。其余八个模块主要行为相同；未覆盖桌面之前修复的会议数据结构、超时结束、删除取消保留状态、用户提示及随机访问路径。

汇报支持 PDF/文本、场景/时长、14 种样式、大纲编辑、预览和 PPTX 下载。增加切换科研菜单保留未保存编辑、保存失败可重试、取消删除显示正确提示。

## 服务检查与重启

5181 的代理目标为 8095，科研接口实际仍到回环服务 8100。发现运行接口落后于磁盘源码：缺少样式列表、PPT 编辑/删除及 ZIP 检查/编译。
经用户明确授权，检查无活动连接和子任务，备份 1,053 个服务文件及数据和受限权限启动信息，再 SIGTERM 优雅退出原进程并沿用原环境和命令启动。未强制终止任务，未修改服务器源码、配置或其他服务。新接口加载确认通过；备份位置和哈希见 server-restart.json。
