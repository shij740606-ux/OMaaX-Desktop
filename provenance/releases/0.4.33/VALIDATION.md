# 0.4.33 登录与知识库修复

## 行为

- 每次正常启动锁定到用户名和密码登录页，不自动恢复旧令牌。只有密码验证成功后的内部重启可以消费一次性安全存储凭证，进入对应账号目录；随后关闭重开仍需点击登录。
- “记住账号和密码”默认关闭。勾选后仅在系统凭据存储中保存，重新打开时填入并遮盖密码，不自动提交。取消勾选立即清除；退出账号不删除配置或历史。保存凭据的读写入口仅允许应用 UI 视图调用。
- 普通登录账号继续拥有普通功能；知识库要求 qa。管理员、账号绑定和删除人工确认规则保持不变。
- “新建问答”立即创建会话、选中新会话并聚焦输入框；失败保留原会话，处理中禁止重复操作。
- 回答使用 Markdown 展示标题、列表、表格和图片。图片仅通过配置服务的 `/api/figures/proxy` 路径请求，令牌留在原生进程；拒绝跨源、重定向及非支持的图片类型，限制图片体积，显示失败可重试。
- 云端当前会丢弃 assistant 的独立 text 字段；现在同时保存标准 TextBlock，恢复时兼容已有 HTML TextBlock。禁止执行回答 HTML，正文中的外链仍受协议检查。服务端此前未保存的正文无法自动补回。
