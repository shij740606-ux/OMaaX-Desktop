# OMaaX 0.4.57 稳定版源码发布

日期：2026-10-26。基于 `0.4.53` 稳定提交 `94baaf73332099d44638821d7d1ba5caac1b3f6c`，汇总 54–57 版功能与修复。

## 功能与修复

- 主对话支持生成、继续修改 Word/PPT/PDF，并保存到项目；分析结果提供项目文档入口。文档与浏览器工具复用现有公司模型服务。
- 知识库问答增加云端返回的检索进度和答案流式显示；图片按账号、会话保存在本机，历史会话优先使用已保存图片。
- 合并课题图谱与研究建议为“课题研究”，资料区默认折叠，主区切换关系图谱和下一步建议。问答来源与保存项目独立选择；交给主对话时显示简短说明，后台携带完整研究上下文。
- 改善图谱布局、异步计算和错误反馈，补齐新增页面的窗口拖动区域。
- 设置第一项改为“账号与支付”，接入微信/支付宝收款、查单、关单与本机订单记录，移除演示套餐和余额。尚不提供套餐、余额或 Token 入账，扩展条件见 [支付接入说明](../../../BILLING_HANDOVER.md)。
- 论文拼图支持直接编辑新增文字、多行与双击修改、选中删除及撤销；新矩形默认透明，A–Z 标签可以独立添加和修改。
- 区分登录过期、权限、网络、超时、校验程序和模型临时凭据错误，避免统一误报为“API 密钥无效”。临时状态校验失败保留已打开页面；真正退出和失效仍正常拦截。
- 修复并发会话刷新临时模型凭据的竞争：同一公司模型桥进程内共享缓存与刷新任务，请求等待正在进行的刷新。单次模型请求在凭据被拒绝后最多刷新重试一次，不无限重试，也不重播已开始的流式输出。
- 修复内置服务器工具外层约 60 秒提前超时，等待时间跟随工具设置并保留取消；修复切换页面后审批卡片缺少操作详情。

## 稳定底座与保护边界

继续固定 DSH `0.1.5-rc.1`，嵌套 agent loop `0.1.5-rc.3`。构建调用 `verify-stable-runtime.mjs`；48 版 `0.2.1-rc.2` 新底座及其 `verify-dsh-runtime.mjs` 专用脚本不纳入本次提交。

保留自动续接、服务器能力、已登记原始数据路径的软件层保护、固定分析流程、审计日志、现有配置和旧对话。原始数据的软件层保护不等于操作系统隔离。

构建继续保护自有 SSH、文档与浏览器核心模块；开源 SDK 与公司桥不宣称为全部加密。源码仓库不提交安装包、个人凭据、真实账号表、对话数据、构建缓存及本机运行记录。
