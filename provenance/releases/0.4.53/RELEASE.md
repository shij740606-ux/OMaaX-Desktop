# OMaaX 0.4.53 稳定版源码发布

日期：2026-10-24。由 `0.4.49` 稳定提交 `8e75e7b` 继续开发，汇总 50–53 版已交付改动。

## 功能与修复

- Windows 安装前检查旧进程与文件占用，安装后校验主程序版本、文件哈希和实际文件位置，防止仍运行旧程序。
- 长对话请求超大时分段整理历史，保留任务状态后继续；输出截断后自动续接，保留停止操作。
- 恢复可用的扩展工具来源，隐藏不能恢复来源的条目；工具仍在用户点击添加后下载。
- 补齐主界面、服务器管理、科研绘图、教育科研及常见状态的英文。用户输入、项目名和论文原文保持原样。
- 科研绘图增加论文拼图与精修：导入、图层、分组、对齐、面板标签、对话修改、项目保存、SVG 和 PNG 导出。
- 更新品牌字标并加入约 5 秒内置启动视频；52 版修复登录、注销和切换账号导致的重复播放。
- 53 版修复对话子页面在 HTML 根节点建立前读取语言引发的异常，使原有品牌隐藏、过程折叠和对话装饰正常执行。

## 底座与数据边界

本版继续使用 47 系列稳定底座：DSH `0.1.5-rc.1`，对应嵌套 agent loop `0.1.5-rc.3`。48 版 `0.2.1-rc.2` 新底座、源码备份及安装包单独保留，不合并到本次代码提交。正式构建调用 `verify-stable-runtime.mjs`，不使用 48 专用的 `verify-dsh-runtime.mjs`。

保留原有公司模型服务、本地与服务器任务、原始数据保护、固定分析流程和审计日志。原始数据保护仍是已接入工具的软件层保护，不等同于操作系统隔离。发布不包含用户凭据、个人配置、聊天记录、分析数据、构建缓存或安装包二进制。

## 验证与交付

- 53 版启动与原生界面针对性测试：14 项通过；TypeScript 检查通过。
- 真实随包 DSH 页面使用隔离数据验证中英文首页、刷新、新会话、输入草稿及语言切换；修复后 14 条观察通过，无页面异常、外部网络请求或模型请求。过程折叠用合成消息 DOM 验证，没有生成真实模型回复。
- 最终安装包两套完整性检查均通过，覆盖 26,179 个文件；包内原生初始化脚本与浏览器验证的脚本完全一致，旧的不安全读取语句已不存在。
- 与 52 比较，26,170 个资源文件字节相同。变化限于主程序、版本化图标名称及 7 个重新加密模块；这些模块的解密内容与 52 相同，图标内容相同。
- 隔离包检查确认 31 个工具注册、匿名操作拒绝、加密模块正常加载，以及启动标记与认证校验保持独立。
