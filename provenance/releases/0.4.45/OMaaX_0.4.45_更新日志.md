# OMaaX 0.4.45 更新日志

发布日期：2026-10-22 · Windows 64 位

## 科研绘图

- 左侧新增「科研绘图」，支持对话生成和修改、手动调整、保存到项目及重新打开。
- 生物示意图提供 18 个精选素材，可搜索、拖入、缩放、旋转、分组和调整图层，支持 SVG 和 PNG 导出。
- 新增分子结构与对接结果查看，可选择配体与姿势、调整显示样式、结合位点范围和标签，并保存视角与显示设置。
- 支持在本机或服务器分析蛋白与配体相互作用，查看二维相互作用图、残基明细及姿势比较。
- 二维示意图可导出真正的矢量 SVG；三维结构图导出高清 PNG。分子功能分析已有结构与对接结果，不执行对接计算。

## 分析流程更顺畅

- 空配置不再阻挡流程；能识别的参数自动转换到对应位置，减少因填写格式不同而反复报错。
- 参数不明确时指出具体步骤和字段；同一参数出现不同值时提示调整，不擅自选择。
- 移除对话顶部累计用量提示；累计调用次数和用量不作为软件额外暂停对话的条件。模型服务自身的余额、限流和单次输出长度限制仍然有效。

## 教育科研

- 教育科研功能改为在本机运行，无需连接 175 服务器；模型功能使用本机此前保存的直连凭据。
- 期刊规则和基础数据随软件提供，文档解析、任务记录及生成文件保存在本机。
- 修复部分期刊规则加载、文档处理和任务保存问题。
- 首次使用需要联网准备运行依赖；调用模型仍需网络和有效的模型凭据。服务器上的旧教育任务不会自动迁入本机。

## 知识库问答

- 支持中止正在等待的问答或检索，并继续发起新问题。
- 支持复制问题、回答、来源和检索结果，以及图片复制。
- 中止后保留已显示内容；服务端是否同时停止计算取决于服务端支持。

## 数据保护与界面

- 在「数据保护与审计」顶部管理原始数据保护路径，查看已保护目录。
- 已接入的文件工具禁止写入、覆盖或删除受保护路径，仍允许读取、复制和建立软链接；操作继续记录审计日志。
- 优化登录页面、环境列表及服务器管理展示，使用更易懂的功能名称和说明。
- 数据保护属于软件层保护，自定义脚本仍存在绕过风险，不等同于系统级只读隔离。

## 安装说明

关闭 OMaaX 后运行 `OMaaX_0.4.45_x64-setup.exe`，覆盖升级即可。无需先卸载或删除用户数据目录；保留原有配置和对话记录。

本次仅提供安装包，由用户自行安装验证。
