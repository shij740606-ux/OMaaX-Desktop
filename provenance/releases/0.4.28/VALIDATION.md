# OMaaX 0.4.28 界面调整验证

## 改动

- 分析默认恢复原有工作区产出卡片、文件分类及推荐分析。在同一页面增加长流程结果和服务器结果入口。
- 长流程保留预览、分页下载、失败产物及确认续跑。服务器结果复用任务日志、结果下载和项目/对话文件管理，删除确认不变。
- 账号和用量移到设置；左侧账户入口及余额弹窗移除。保留原有套餐演示，同时显示真实模型余额和本对话/本项目/全部对话 tokens。
- 教育科研删除顶部返回问答按钮，九个功能模块不变。

## 本次验证

- TypeScript 检查、React 生产构建及 Vue 科研生产构建通过。
- 设置/服务器组件回归 34 项通过，包括新增的实际 token 聚合检查。
- 新导航浏览器 4 组通过：原分析布局、服务器结果下载、删除取消、设置账户、科研九模块和无返回按钮；页面异常为零。
- 长流程浏览器 13 组通过：文本/图片/隔离 HTML 预览、分页、下载、失败结果、确认续跑、服务器切换迟到响应、连接恢复及窄窗口。
- 账号浏览器 7 组通过：登录与授权边界、设置内入口、套餐选择和演示支付、退出清理及窗口宽度。
- 浏览器测试使用真实 React/Vue 和 Edge、模拟接口；未启动新的真实模型分析。

首次浏览器检查受到旧测试服务和过期依赖缓存影响，核对进程后终止本轮测试服务，改用独立缓存和静态科研页面重跑通过。编译保留原有大文件分块和混合导入提示，无构建错误。

安装包资源校验和安装数据核对见同目录 JSON。账号演示数据仍不代表真实账单。

0.4.28 已原位安装，28 个资源哈希核对通过，49 个配置及对话文件均未变化。最终安装版四组入口检查通过，页面异常为零。桌面仅保留当前安装包和 0.4.27 回退包。
