# OMaaX 0.4.40 更新日志

## 本次更新

- 推理模式移至对话输入框工具栏，保留低、中、高三档，取消顶部重复入口。
- 对话界面隐藏系统提示词区域；模型仍接收执行任务所需的系统指令。
- 更新绿色应用图标，生成 Windows ICO、macOS ICNS 及不同分辨率资源。
- 取消本地“80 次调用或 200,000 tokens 后暂停”的限制，继续记录用量。旧会话达到旧上限也不会因此被阻止。公司服务端自身的额度、授权和限流规则不变。
- 一体化流程保留所选流程和软件要求，模型可以读取资料、配置 Conda 依赖、调整流程声明的参数、读取日志、修复安装错误及保存结果。
- 删除前仍展示路径、范围和大小，按现有确认规则执行；覆盖已有文件仍须确认并备份。默认保留输入文件，结果另存。
- 保留长流程日志、修复重试、断点续跑、计算节点提交和结果追踪。
- 更新安装不迁移或清空用户配置及对话记录。

## 验证记录

- JavaScript 回归：130 项通过。
- 原生 Rust 回归：42 项通过，3 项需显式连接外部环境的测试未由默认套件执行。
- Windows Python 回归：192 项中 167 项通过，25 项平台相关跳过。
- 真实 Linux 环境：192 项全部通过，无跳过。
- 浏览器回归：登录、知识库、工具入口、结果展示、推理模式位置与提示词隐藏均通过。
- 真实公司模型连接真实服务器：在隔离目录故意触发安装错误，模型读取日志、修改安装方案、再次安装并通过软件就绪检查；未使用 sudo 或 Podman。
- 实际 SDK 到原生执行层再到 Slurm：两步小数据流程提交、执行、结果追踪通过。该链路使用确定性模型夹具，真实模型的环境修复另外独立验收。
- 实际 SDK 验证：公司模型桥接、外部工具、超过旧 token 上限继续执行及删除保护均通过。
- Windows 原生界面：三档切换及后端保存、系统提示词隐藏、知识库图片及历史恢复、外部文件夹访问、每次启动重新登录、记住及清除密码共 7 组检查通过。
- 最终安装后再次完成以上 7 组检查；445 个配套资源与源文件一致，153 个原用户配置及对话文件的 SHA-256 与升级前完全一致。
- Apple 芯片安装包已在 macOS ARM64 构建机生成，确认主程序为 ARM64，随包 Node 运行时可运行；下载文件与构建机 SHA-256 一致。

以上为功能和小数据验收，不代表所有生物学流程在所有集群上均完成真实大数据验证。

## 平台说明

- Windows：0.4.40，保留原用户配置和对话数据，保留最近一次旧版安装包用于回退。
- macOS：面向 Apple 芯片（M1/M2/M3/M4 等），最低 macOS 12；`OMaaX_0.4.40_Apple芯片.dmg` 已放到桌面。
- macOS 安装包未使用 Apple 开发者证书签名及公证，首次打开可能受到系统安全检查；尚未在用户自己的 Mac 上进行人工验收。
